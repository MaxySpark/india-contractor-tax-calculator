# India contractor tax calculator

Compare US export billing, Indian contractor billing with GST included or excluded, and employee salary, including Section 44ADA assumptions.

## Use

Open [the calculator](https://maxyspark.github.io/india-contractor-tax-calculator/) or download and open `index.html` in a browser. No installation or build required.

The calculator was imported unchanged from the supplied HTML file. Tax calculations and legal assumptions have not been independently verified; consult a qualified tax professional before relying on the results.
